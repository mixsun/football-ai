# 半场有球雷达

Vue 3 + TypeScript + Vite 实现的 Titan007 即时比赛分析页。开发服务器从 Titan 公共即时数据读取赛程、比分、进球事件、欧赔、亚盘和大小盘，浏览器只访问本地 `/api/live`。

读取层采用双通道：优先请求公开数据文件；如果 Titan 拒绝命令行连接，则自动调用本机无界面的 Edge/Chrome 打开官网并读取页面已经加载的数据。回退模式不会弹出额外浏览器窗口。

## 运行

双击 `启动分析工具.bat`，或执行：

```bash
npm install
npm run dev
```

访问 <http://127.0.0.1:4173>。生产检查可执行 `npm test` 与 `npm run build`。

## 判断方法

- 上半场只要已经出现进球：无论进球时间和当前进球数，继续估算剩余时间再进至少一球的概率，并标记为“下一球”。
- 剩余时间窗口包含预计4分钟上半场补时；任一上半场比赛进入35分钟后，自动刷新由2分钟切换为30秒，降低末段进球回写遗漏。
- “上半场”列表会把中场状态保留到下半场开始，并对40分钟后及中场比赛额外读取浏览器实时列表，用于核对直接比分源可能延迟的末段进球。
- 仍为上半场 0:0：将半场和全场大小盘水位换算为去水概率，以盘口球数估计上半场期望进球，再按剩余时间作泊松折减。
- 其他比赛：保留在“全部进行中”中展示，但不输出上半场下一球概率。

“同盘口当前样本”是当前数据流中半场亚盘与半场大小盘相同的比赛数量，不代表历史命中率。模型未纳入红牌、伤停和实时攻势，仅供研究。

盘口详情优先采用 Crow*；若该公司没有为某场比赛开盘，则回退到页面中第一家有完整数据的公司。源站没有任何盘口时显示“—”，不会用估算值冒充真实赔率。

每次打开页面或点击“立即刷新”都会重新抓取当前比赛，并逐场补充欧赔、亚盘和大小盘详情，不复用上一次请求的盘口缓存。由于需要访问每场详情页，一次完整刷新通常需要数秒至数十秒。
